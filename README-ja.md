# Daigo Kitagawa's Portfolio
作成したプロジェクトについて紹介している北川大悟のポートフォリオ。

## 概要
- **About me**:　私に関してのおおまかな説明
- **Projects**:　いくつかの作成したプロジェクトの紹介

## 技術スタック
- **ライブラリ**:　React
- **言語**:　JavaScript

## ディレクトリ構造
```
src/
├── assets/                 # 外部からのフォントと画像
│   ├── fonts/              # InterとManropeフォント
│   └── images/             # プロジェクトとローディング画面用の画像
├── components/             # Reactコンポーネント
│   ├── Achievements/       # プロジェクトカードとカードスライダーの合体
│   ├── Card/               # プロジェクト表示用のカードコンポーネント
│   ├── Introduction/       # About me用の自己紹介コンポーネント
│   ├── LanguageToggle/     # 未実装
│   └── LoadingScreen/      # ペンギンのローディング画面
├── data/
│   └── data.js             # プロジェクトカード用のデータ
├── App.jsx                 # コンポーネントの合体
├── index.css               # フォントをInterへと変更
└── main.jsx
```
